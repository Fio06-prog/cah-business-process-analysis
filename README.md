# CAH Business Process Analysis

## Project Overview

This project focused on analyzing and improving business processes within an organizational environment.

The objective was to identify inefficiencies, model existing workflows, and propose improvement opportunities using BPMN methodology.

## Objectives

- Analyze existing business processes
- Identify bottlenecks and inefficiencies
- Model processes using BPMN
- Propose process improvement opportunities

## Methodology

- Business Process Analysis
- BPMN Modeling
- Process Mapping
- Root Cause Analysis

## Skills Demonstrated

- Business Analysis
- BPMN
- Process Improvement
- Documentation
- Analytical Thinking
